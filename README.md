# Custom System

A versatile system for managing player data in FiveM.

## Features

- Update player values with a command
- Retrieve player data with a callback

## Requirements

- FiveM server
- QB-Core framework
- MySQL database

## Installation

1. Download the script
2. Place it in your FiveM resources folder
3. Add `ensure customsystem` to your server.cfg

## Usage

### Commands

- `/updatevalue [number]` - Update your value

### Permissions

- Players can use the `/updatevalue` command

## Configuration

Edit the `config.lua` file to configure the database and system settings.
